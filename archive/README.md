# Versões preservadas

- `original_html/`: versão original com cálculo em JavaScript, usada pela auditoria histórica.
- `previous_distribution/`: arquivos restantes da distribuição anterior, incluindo o antigo `ui.js` monolítico, mantidos para consulta.

O site ativo usa `frontend/` e `voltcalc/`. Estes arquivos históricos não são servidos pelo servidor e não devem receber novas funcionalidades. Inicie o projeto pelo `Iniciar_VoltCalc.bat` da raiz ou por `python server.py`.
