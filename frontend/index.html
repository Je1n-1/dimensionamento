Abra o VoltCalc com o servidor Python

O arquivo HTML sozinho não executa os cálculos. Primeiro, inicie o servidor local.

  1. Abra a pasta do projeto VoltCalc.
  2. Dê dois cliques em Iniciar_VoltCalc.bat ou execute python server.py --open no terminal dessa pasta.
  3. Mantenha a janela do servidor aberta enquanto usa o site.

Depois de iniciar o servidor, abrir o VoltCalc.

Se a conexão falhar, volte a esta página e confira se o servidor está aberto. Nenhum projeto salvo foi apagado.
